# Xscriptor Packages

npm packages for installing Xscriptor AI agents and skills.

## Contents

- `ai-agents/` — `@xscriptor/ai-agents` (main installer)
- `skill-xscriptor/`, `skill-devx/`, `skill-samurai/` — project skill packages

## Install

```bash
npx @xscriptor/ai-agents
```

Full registry: [xscriptor-ai/agents-hub](https://github.com/xscriptor-ai/agents-hub)
